# Campaign Library

## Purpose

The Campaign Library is the permanent record of all completed campaign knowledge.
Completed campaigns are never permanently deleted.

## Library Categories

High Performing · Low Performing · Evergreen · Completed ·
Cancelled · Experiments · Seasonal · Archived

## Filter Dimensions

Workspace · Objective · Channel · Content type · Product/service/offer ·
Date · Performance classification · Revenue · Engagement · Hook · Audience ·
Creative style

## Cancellation

Cancelled campaigns must include a `cancellation_reason`.
Cancelled campaigns remain in the library — they are a source of learning.

## Rejected Content

Rejected revision instructions and replaced versions are preserved.
They are useful learning data — they show what the user did not want.

## Library vs Archive

- **Completed** → natural end of a campaign measurement window
- **Archived** → manually moved to long-term storage; still queryable
- **Cancelled** → stopped before completion; reason required
